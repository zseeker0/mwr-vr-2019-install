# Phase 3 — Applying the verified files

This page covers the detailed steps for applying this kit after the game and
the Overlord mod are installed. For the full new-PC sequence, start with
`NEW_PC_WALKTHROUGH.md`.

## Prerequisites

- Phase 1 complete: `h1_sp64_ship.exe` matches the 2019/1.15 identity below.
- Phase 2 complete: a normal Overlord installation exists in the game folder.
- Game, MWR launcher and SteamVR are all closed.

## 1. Confirm the game version

```powershell
Get-Item 'h1_sp64_ship.exe' | Select-Object Length
Get-FileHash 'h1_sp64_ship.exe' -Algorithm SHA256
```

| Property | Expected |
| --- | --- |
| Size | `20213128` bytes (`0x1346D88`) |
| SHA-256 | `3d23e86930668244d43a026552d5e1298a7c8cc63b82a54a7ad857e7b41f9190` |
| PE timestamp | `0x5D374DBA` (2019-07-23) |
| PE format | x64 PE32+, 11 sections |
| Image size | `0x12654800` |

Stop if the hash does not match.

## 2. Install

Open PowerShell in this repository's root and run:

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install.ps1
```

The script:

1. Prompts for the game folder (the one containing `h1_sp64_ship.exe`).
2. Re-checks the game hash and aborts on a mismatch.
3. Creates a timestamped `overlord-preinstall-backup-*` folder in the game
   directory and copies any existing mod files there.
4. Copies the verified files from `files/`.
5. Verifies the SHA-256 of all three binaries against the manifest.
6. Selects English by renaming `zone\russian` to `zone\_russian` when present.

## 3. Verify the installation

```powershell
powershell -ExecutionPolicy Bypass -File scripts\verify.ps1
```

Expected output ends with `VERIFY_OK`.

## 4. Register with SteamVR if needed

```powershell
& '<steam-root>\steamapps\common\SteamVR\bin\win64\vrpathreg.exe' addmanifest '<game-folder>\overlord.vrmanifest'
```

Restart SteamVR afterwards.

## 5. First run

1. Start SteamVR; confirm headset and controllers are tracked.
2. Run `overlord.exe` from the game folder; choose **Singleplayer**.
3. Wait roughly two minutes for unpacking. Dismiss any autosave warning popup.
4. In the console run `map killhouse`.
5. Follow `GAME_VIEW.md` for visual confirmation.

`cl_ingame=unavailable` may appear in diagnostics because that symbol is
unresolved in this build. It is not a failure indicator.

## 6. Revert

```powershell
powershell -ExecutionPolicy Bypass -File scripts\restore.ps1
```

Restores the newest backup. The game itself, saves and other mod folders are
left untouched.
